#  Bloom & Grow

A cozy and interactive indoor plant care application built with React and Vite.

Bloom & Grow helps plant lovers discover beautiful houseplants, create a personal plant collection, and keep track of their watering activities.

##  Features

- **Plant Spotlight** — Explore six featured houseplants through an interactive image slider.
- **Explore Plants** — Browse a catalog of 16 indoor plants with photos, scientific names, and basic care information.
- **My Plants** — Create and manage your personal plant collection.
- **Watering Tracker** — Record the last watering date for each plant in your collection.
- **Local Storage** — Keep your plants and watering history saved between browser sessions.
- **Responsive Design** — Enjoy a comfortable experience across desktop, tablet, and mobile screens.

##  Technologies Used

- React
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite
- React Hooks (`useState`, `useEffect`)
- Local Storage API

##  Getting Started

To run this project locally:

1. Clone the repository:

   `git clone https://github.com/LeahLogic/bloom-and-grow.git`

2. Navigate to the project folder:

   `cd bloom-and-grow`

3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`

5. Open the local URL displayed in your terminal.

##  How It Works

Browse the plant catalog and click **+ Add Plant** to add a plant to your personal collection.

Switch to **My Plants** to view your selected plants, mark them as watered, or remove them from your collection.

Your collection and watering dates are stored locally in your browser, so they remain available after refreshing the page.

##  Design

Bloom & Grow features a nature-inspired design with botanical colors, elegant typography, cozy plant photography, and responsive layouts.

The interface is designed to make everyday plant care simple and enjoyable.
